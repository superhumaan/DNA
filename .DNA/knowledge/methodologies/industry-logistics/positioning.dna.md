# Logistics Delivery

Industry overlay for **supply chain & freight**. Pair with a company-size pack (`companies/*`) and a base process (`methodologies/scrum|kanban|shape-up|safe|dna-default`).

## When to load
- Product is regulated or domain-heavy in supply chain & freight
- Agency engagements where `industry.active` = logistics
- Roadmaps must reflect domain risk, not generic SaaS velocity

## Pairing
| Layer | Pack |
|-------|------|
| Size | companies/startup … companies/enterprise |
| Process | scrum / kanban / shape-up / safe / dna-default |
| Industry | methodologies/industry-logistics |
| Compliance | install via `dna plan compliance` / legal packs |

## Domain hooks
- Tracking SLAs, partner EDI, exception ops
- Pair: logistics/*, industries/logistics-supply-chain

## Grounding (mandatory)
1. Run DNA CLI analyze/scan before recommending upgrades
2. Read CellularMemory debt/blockers for this domain
3. Impression Guard — stub policies ≠ implemented controls
