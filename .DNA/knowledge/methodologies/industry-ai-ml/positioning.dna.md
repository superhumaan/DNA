# AI / ML Products Delivery

Industry overlay for **ML-powered product surfaces**. Pair with a company-size pack (`companies/*`) and a base process (`methodologies/scrum|kanban|shape-up|safe|dna-default`).

## When to load
- Product is regulated or domain-heavy in ML-powered product surfaces
- Agency engagements where `industry.active` = ai-ml
- Roadmaps must reflect domain risk, not generic SaaS velocity

## Pairing
| Layer | Pack |
|-------|------|
| Size | companies/startup … companies/enterprise |
| Process | scrum / kanban / shape-up / safe / dna-default |
| Industry | methodologies/industry-ai-ml |
| Compliance | install via `dna plan compliance` / legal packs |

## Domain hooks
- Evals, drift, human oversight, model cards
- Pair: ai/*, combo/ai-rag-product, companies/research-lab

2. Read CellularMemory debt/blockers for this domain
