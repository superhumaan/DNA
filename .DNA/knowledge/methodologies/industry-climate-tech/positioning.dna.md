# Climate Tech Delivery

Industry overlay for **climate / ESG / carbon software**. Pair with a company-size pack (`companies/*`) and a base process (`methodologies/scrum|kanban|shape-up|safe|dna-default`).

## When to load
- Product is regulated or domain-heavy in climate / ESG / carbon software
- Agency engagements where `industry.active` = climate-tech
- Roadmaps must reflect domain risk, not generic SaaS velocity

## Pairing
| Layer | Pack |
|-------|------|
| Size | companies/startup … companies/enterprise |
| Process | scrum / kanban / shape-up / safe / dna-default |
| Industry | methodologies/industry-climate-tech |
| Compliance | install via `dna plan compliance` / legal packs |
