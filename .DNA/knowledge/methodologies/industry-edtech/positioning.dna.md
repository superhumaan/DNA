# EdTech Delivery

Industry overlay for **education technology**. Pair with a company-size pack (`companies/*`) and a base process (`methodologies/scrum|kanban|shape-up|safe|dna-default`).

## When to load
- Product is regulated or domain-heavy in education technology
- Agency engagements where `industry.active` = edtech
- Roadmaps must reflect domain risk, not generic SaaS velocity

## Pairing
| Layer | Pack |
|-------|------|
| Size | companies/startup … companies/enterprise |
| Process | scrum / kanban / shape-up / safe / dna-default |
| Industry | methodologies/industry-edtech |
| Compliance | install via `dna plan compliance` / legal packs |

## Domain hooks
- Student data privacy, LTI/SCORM, academic integrity
- Pair: edtech/*, industries/edtech

## Grounding (mandatory)
1. Run DNA CLI analyze/scan before recommending upgrades
2. Read CellularMemory debt/blockers for this domain
3. Impression Guard — stub policies ≠ implemented controls
