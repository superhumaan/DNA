# Manufacturing Delivery

Industry overlay for **industrial / MES / IoT ops**. Pair with a company-size pack (`companies/*`) and a base process (`methodologies/scrum|kanban|shape-up|safe|dna-default`).

## When to load
- Product is regulated or domain-heavy in industrial / MES / IoT ops
- Agency engagements where `industry.active` = manufacturing
- Roadmaps must reflect domain risk, not generic SaaS velocity

## Pairing
| Layer | Pack |
|-------|------|
| Size | companies/startup … companies/enterprise |
| Process | scrum / kanban / shape-up / safe / dna-default |
| Industry | methodologies/industry-manufacturing |
| Compliance | install via `dna plan compliance` / legal packs |

## Domain hooks
- OT/IT boundary, downtime risk, traceability
- Pair: iot/*, industries/energy-utilities adjacent

## Grounding (mandatory)
1. Run DNA CLI analyze/scan before recommending upgrades
2. Read CellularMemory debt/blockers for this domain
3. Impression Guard — stub policies ≠ implemented controls
