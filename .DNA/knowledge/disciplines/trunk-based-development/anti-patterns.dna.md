# Trunk-Based Development — Anti-patterns

- Committing secrets or tokens
- Treating stub Impressions as implemented controls
- Skipping staging verification
- Silent failures without alerts
- **Inventing `feature/*` remotes** or hopping branches "to test on preview"
- **Dual-tracking** the same feature across multiple remotes then recovering by preview hops
- Long-lived `develop` branch as a second trunk
- Agents deciding their own fate: inventing slogans, parallel architectures, or forgetting CellularMemory
